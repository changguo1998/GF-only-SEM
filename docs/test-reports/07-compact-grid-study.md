# 紧凑全空间五网格研究

## 测试目的

判断全空间解析误差是否随空间网格加密收敛，并区分离散误差、统一幅值错误和有限边界返回。

## 测试方法

在相同 18 km 立方域、同一物理震源和 64 个固定物理接收点上，仅改变网格数。每个网格
完整运行 CUDA 三方向正演与 MPI 后处理，再与 Stokes 全空间解比较。2026-09-20 在修复
三倍计数和拟合 L2 公式后重算全部五组。

## 参数选择

- 网格：18³/20³/22³/24³/28³，对应 3.0/3.3/3.7/4.0/4.7 单元每 S 波长。
- 公共参数：N=4、1 Hz Ricker、8 s、`vp/vs/rho=5000/3000/2700`。
- 接收点：seed 0 的 64 个固定点，范围 `[5.5,12.5] km³`；解析解在最近真实 GLL 坐标计算。
- PML 物理厚度约 5 km；HDF5 不压缩。

## 测试结论

| 网格 | corr | 原始 L2 | SEM/参考 scale | 拟合 L2 |
| --- | ---: | ---: | ---: | ---: |
| 18³ | 0.8502 | 0.4599 | 1.016 | 0.3414 |
| 20³ | 0.8476 | 0.4629 | 1.038 | 0.3458 |
| 22³ | 0.8405 | 0.4613 | 1.013 | 0.3436 |
| 24³ | 0.8321 | 0.4656 | 1.032 | 0.3468 |
| 28³ | 0.8467 | 0.4625 | 1.026 | 0.3443 |

- 3.0→4.7 单元/λs 内拟合 L2 无单调改善，紧凑域残差不是分辨率主导。
- scale 稳定接近 1，已排除旧的统一三倍幅值问题。
- 28³ 是当前主机商定上限；估算 32³ 后处理约需 89 GB。
- 旧 0.338–0.346 scale、旧 shape L2 以及混入 PML 的硬编码接收区结果均已失效。
