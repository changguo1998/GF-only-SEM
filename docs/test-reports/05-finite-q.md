# 有限 Q SLS 本构与传播测试

## 测试目的

分别验证 SLS 本构公式、Q→∞ 弹性极限、Qμ/Qκ 独立响应、时间步细化稳定性，以及有限 Q
波在 1–2 个 S 波长传播后的幅值衰减和相位频散。

## 测试方法

本构层使用 SPECFEM 的 Qμ=20 剪切、Qκ=10 体积复模量作为独立参考。传播层同时运行
弹性和粘弹性 y 向点力，以远/近接收点传递函数之比消除共同的震源、网格和 PML 误差，
在 0.75/0.875/1.0 Hz 对照解析复波数。

2026-09-24 修复了分析器对 Debug `all_local_cells` record 的读取，并用当前代码重跑
单 GPU CUDA 和 2-rank CPU。尺寸对照发现原模型的非 PML 横截面过窄，因此在保持
单元尺寸、PML 厚度、频率和传播距离不变的前提下，将横截面从 12×12 km 扩至
14×14 km；两后端结果在表中精度内相同。

## 参数选择

- 网格：20×14×14、N=4、20×14×14 km，3920 单元。
- 介质：`vp=5000 m/s`、`vs=3000 m/s`、`rho=2700 kg/m³`。
- 衰减：Qμ=20、Qκ=1e9、3 个 SLS、参考频率 1 Hz。
- 震源：1 Hz Ricker，中心 1.2 s；总时长 4.4 s。
- 时间：`solver_dt=0.016 s`、输出 stride=5、55 帧。
- 相对原 2 Hz 算例，x 方向与时间尺度严格乘 2；保持 3 单元/λs、5 单元 PML、
  时间步/周期和快照数不变。横向各增加 2 个单元，使非 PML 宽度由 2 km 增至 4 km，
  超过一个 3 km S 波长；两个接收点仍位于一、二个 S 波长处且不进入 PML。
- 门限：振幅相对误差 ≤12%，相位误差 ≤0.11 rad。

## 测试结论

本构单元测试和 Q→∞ 回归通过；当前传播结果为：

| 频率 | 实测幅值比 | 解析幅值比 | 振幅误差 | 相位误差 |
| ---: | ---: | ---: | ---: | ---: |
| 0.750 Hz | 0.944772 | 0.903078 | 4.62% | 0.0023 rad |
| 0.875 Hz | 0.924434 | 0.875976 | 5.53% | 0.0045 rad |
| 1.000 Hz | 0.900680 | 0.847716 | 6.25% | 0.0084 rad |

- 三个频点的振幅和相位全部通过，当前传播级总判定为通过。
- CPU/CUDA 指标在报告精度内相同。CUDA 弹性/粘弹耗时 5.90/5.62 s，2-rank CPU 为
  71.43/70.18 s。
- 20×12×12 对照的最大振幅/相位误差为 13.67%/0.0744 rad；横向扩至 14×14 后降至
  6.25%/0.0084 rad。唯一改变的是横向物理区宽度，证明失败主要来自过近 PML/边界返回，
  而不是 1 Hz 降频、SLS 本构、时间步或某一计算后端。
- 20×14×14 是保持 1 km 单元、源点相对网格位置和横向对称性的最小整数单元扩展。
