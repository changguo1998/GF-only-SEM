# 全空间参考解时间收敛验证

## 测试目的

确认 Stokes 全空间参考解的时间离散、传播延迟和近场积分不会把参考误差错误归因于 SEM
正演。测试同时对比旧的输出时间步算法和新的分段线性参考实现。

## 快速参数组合

- 网格：20×20×20、18 km 立方域、N=4、900 m 单元、六面各 6 层 C-PML。
- 介质：`vp=5000 m/s`、`vs=3000 m/s`、`rho=2700 kg/m³`；1 Hz Ricker 点力。
- 震源：`(9375,9375,9375) m`；三种力方向。
- 正演：Debug CPU-MPI、16 ranks、400 步、`solver_dt=0.0125 s`、100 帧、输出间隔
  `0.05 s`；后处理使用 MPI-4。
- 参考解：15 个非 PML 区域点，内部时间步按 1、2、4、8、16、32、64、128 倍细化。
- SEM 波形对照：沿用网格研究的 64 个固定物理比较点，使用 0–5 s 全时段位移张量。

## 结果

| 项目 | 结果 |
| --- | ---: |
| 最高级别细时间网格与直接分段线性积分的最大相对差异 | `2.8e-16` |
| 旧算法与新参考解在 15 个选点的最大相对差异 | `31.4%` |
| 新参考解与 SEM 的平均相关系数 | `1.0000` |
| 新参考解与 SEM 的平均原始相对 L2 | `0.0040` |
| SEM/参考解最佳拟合 scale | `1.001` |
| SEM/参考解拟合相对 L2 | `0.0038` |

参考解细化测试和三方向波形比较均通过。细时间网格与直接积分复用同一分段线性源模型，
`2.8e-16` 是该模型内部的一致性结果，不能当作独立解析式正确性的证据；单元测试另用
`scipy.integrate.quad` 对近场项做独立数值积分检查。旧算法与新实现的差异包括输出步长的
传播延迟取整、源时间函数降采样和近场积分处理，本次未分别量化各项贡献。新实现保留
solver-grid STF，采用分数 P/S 延迟和分段线性源的精确原函数。

## 结论边界

20³ 快速组合确认在这组参数与短时窗下参考解的时间处理有效，不能代替 40³ 全规模重跑，
也不代表所有接收点和频率已验证。历史五网格、扩域和 40³ 对 Stokes 的相关系数、幅值
比例和相对 L2 均使用旧参考解；其误差归因需用新参考解重算后再判断。40³ 原有约 19%
的波形能量误差不能直接当作当前算法的误差。

本次运行的 wavefield、Green tile 和 CSV 均已清理；数值结果保留在本报告中。
