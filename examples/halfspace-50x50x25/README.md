# 50×50×25 大型半空间验证

该算例与40³全空间测试计算规模接近，但顶面为自由表面：

- 总网格50×50×25，62,500单元，1 km/单元；
- 四侧和底部各5层C-PML，物理区为40×40×20 km；
- 默认均匀弹性介质：Vp=5000 m/s、Vs=3000 m/s、密度2700 kg/m³，可替换配置中的速度和密度函数；
- 1 Hz Ricker严格地表震源位于 `(18.5, 25.5, 0) km`，接近物理区x方向1/3位置；
- 一次后处理长轴上的 `x1/x2/x3, y2` 三个tile，覆盖x=`[15,34] km`、
  y=`[23,28] km`；
- 在2/5/8/11/14 km距离、0/1/2 km深度的15个点与Lamb解比较。

比较窗随距离取3.5/4.5/5.5/6.5/7.3 s，均早于镜像路径估算的最早PML返回
5.8/6.4/7.0/7.6/7.8 s。解析Lamb计算使用24点Gauss-Legendre、800段；地表源以
1 m埋深近似。深部点按Johnson公式的适用方式，以深部点为解析源、地表点为接收点，
再按位移互易性转置张量，与正演的地表源→深部采样结果比较。

2026-09-29 Debug CUDA结果：地表2/5/8/11 km点corr为0.980–0.985/0.957，scale为
0.990–1.111；14 km下降到corr=0.899704、scale=0.766436、拟合L2=0.436501。
1–2 km深度的10个点全部达到corr≥0.990522、scale=`[1.003104,1.054427]`、
拟合L2≤0.137358。误差集中在长距离地表响应，支持表面波/自由表面离散误差解释，
而不是整体体波传播或PML返回错误。

运行Debug CUDA全流程：

```bash
bash examples/halfspace-50x50x25/run.sh
```

已有正演record时只重做后处理和解析对比：

```bash
GF_REUSE_WAVEFIELDS=1 bash examples/halfspace-50x50x25/run.sh
```

三方向Debug全域record约197 GiB；三个tile输出约386 MiB。选择tile只降低后处理内存、
计算和Green函数输出量，并不会降低Debug正演快照体积。
